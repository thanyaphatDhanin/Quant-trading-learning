# Alpha Properties: คุณสมบัติของ Alpha

หมวดนี้อธิบายคุณสมบัติสำคัญของ Alpha ในการทำ Quant Trading เพื่อให้เราเข้าใจว่า Alpha แต่ละตัวมีความสามารถ ข้อจำกัด และพฤติกรรมอย่างไร

## What You Will Learn

การพบความสัมพันธ์ระหว่างสัญญาณกับผลตอบแทนในอดีต เป็นเพียงจุดเริ่มต้น เรายังต้องศึกษาเพิ่มเติมว่า Alpha มีคุณสมบัติแบบใด และข้อจำกัดเหล่านั้นส่งผลต่อการนำไปใช้ในกลยุทธ์อย่างไร

ในหมวดนี้ คุณจะได้เรียนรู้แนวคิดสำคัญ ได้แก่

- **Information Coefficient (IC)** — วัดความสัมพันธ์ระหว่างค่าที่ Alpha พยากรณ์กับผลตอบแทนที่เกิดขึ้นจริง
- **Information Ratio (IR)** — วัดผลตอบแทนส่วนเกินเทียบกับความผันผวนของผลตอบแทนส่วนเกิน ตามนิยามและกรอบการประเมินที่ใช้
- **Turnover** — วัดระดับการซื้อขายหรือการเปลี่ยนแปลงสถานะของพอร์ต
- **Capacity** — ประเมินว่ากลยุทธ์รองรับเงินทุนได้มากเพียงใด ก่อนที่ผลการดำเนินงานจะลดลงเกินระดับที่ยอมรับได้
- **Horizon & Holding Period** — ทำความเข้าใจช่วงเวลาที่ Alpha ใช้พยากรณ์ และระยะเวลาที่ถือสถานะจริง
- **Correlation** — ศึกษาความสัมพันธ์ระหว่างผลตอบแทน สัญญาณ Alpha ผลการดำเนินงานของกลยุทธ์ และค่าของตัวแปรในช่วงเวลาต่างกัน
- **Alpha Decay** — ศึกษาการลดลงของความสามารถในการพยากรณ์หรือผลตอบแทนที่สัมพันธ์กับ Alpha ตามนิยามที่กำหนด
- **Robustness** — ตรวจสอบว่าผลลัพธ์ยังคงมีเสถียรภาพภายใต้เงื่อนไขการทดสอบที่เหมาะสมหรือไม่

## Learning Path

อ่านตามลำดับต่อไปนี้ เพื่อทำความเข้าใจจากการวัดความสามารถในการพยากรณ์ ไปสู่ข้อจำกัดในการนำ Alpha ไปใช้จริง

| ลำดับ | หัวข้อ | คำถามหลัก |
|---|---|---|
| 01 | Information Coefficient | Alpha สัมพันธ์กับผลตอบแทนในอนาคตมากน้อยเพียงใด? |
| 02 | Information Ratio | ผลตอบแทนส่วนเกินมีความสม่ำเสมอเมื่อเทียบกับความผันผวนหรือไม่? |
| 03 | Turnover | Alpha ทำให้ต้องซื้อขายบ่อยเพียงใด? |
| 04 | Capacity | กลยุทธ์รองรับเงินทุนได้แค่ไหน? |
| 05 | Horizon & Holding Period | สัญญาณพยากรณ์ผลตอบแทนในช่วงเวลาใด และควรถือตำแหน่งนานเท่าใด? |
| 06 | Correlation | Alpha มีความสัมพันธ์กับข้อมูลหรือสัญญาณอื่นอย่างไร? |
| 07 | Alpha Decay | ความสามารถในการพยากรณ์เปลี่ยนแปลงไปตามเวลาหรือไม่? |
| 08 | Robustness | ผลลัพธ์ยังคงอยู่เมื่อเปลี่ยนเงื่อนไขการทดสอบอย่างสมเหตุสมผลหรือไม่? |

## Important Distinction

**Alpha ที่มีคุณสมบัติน่าสนใจ ไม่ได้หมายความว่ากลยุทธ์จะทำกำไรได้จริงโดยอัตโนมัติ**

ตัวชี้วัดแต่ละตัวตอบคำถามคนละข้อ และต้องตีความตามนิยาม วิธีคำนวณ ชุดข้อมูล และกรอบการทดสอบที่ใช้

การประเมินกลยุทธ์ยังต้องพิจารณาประเด็นอื่นร่วมด้วย เช่น

- Transaction Costs — ค่าธรรมเนียมและต้นทุนการซื้อขาย
- Slippage — ความแตกต่างระหว่างราคาที่คาดหวังกับราคาที่ซื้อขายได้จริง
- Backtesting & Validation — การทดสอบและตรวจสอบผลลัพธ์
- Overfitting & Data Snooping — ความเสี่ยงจากการปรับแบบจำลองให้เข้ากับข้อมูลมากเกินไป หรือการค้นหาผลลัพธ์จากการทดลองหลายรูปแบบ

หัวข้อเหล่านี้จะศึกษาแยกในส่วนที่เกี่ยวข้อง เพื่อไม่ให้ความหมายของแต่ละแนวคิดปะปนกัน
