# Alpha Series

ชุดบทเรียนเกี่ยวกับ Alpha ใน Quantitative Trading ตั้งแต่แนวคิดพื้นฐาน การออกแบบสัญญาณ ไปจนถึงการประเมินคุณภาพและความสามารถในการนำไปใช้งานจริง

## Learning Objectives

เมื่อเรียนจบชุดนี้ ผู้อ่านควรสามารถ:

- อธิบายความหมายของ Alpha ในบริบทของ Quantitative Trading
- แยกแยะสัญญาณที่มีศักยภาพออกจากสัญญาณที่เสี่ยงต่อ Overfitting
- เข้าใจวงจรชีวิตและกระบวนการออกแบบ Alpha
- อ่านและตีความตัวอย่าง Alpha Formula เบื้องต้น
- เข้าใจตัวชี้วัดสำคัญ เช่น IC, IR, Turnover, Capacity, Correlation, Decay และ Robustness

## How to Use This Series

แนะนำให้อ่านตามลำดับ เริ่มจากแนวคิดพื้นฐานก่อนศึกษาสูตรและตัวชี้วัด จากนั้นทดลองตั้งสมมติฐาน ตรวจสอบข้อมูล และประเมินผลด้วยตนเอง

## Research Standards

- แยกข้อเท็จจริง นิยามทางคณิตศาสตร์ และข้อเสนอแนะออกจากกัน
- ระบุแหล่งอ้างอิงสำหรับสูตร ตัวเลข และข้อกล่าวอ้างเชิงวิจัย
- ไม่ถือว่าผล Backtest เป็นหลักฐานยืนยันผลตอบแทนในอนาคต
- ระบุเนื้อหาที่ยังตรวจสอบไม่ครบหรือมีข้อมูลไม่สมบูรณ์อย่างชัดเจน
- เนื้อหานี้จัดทำเพื่อการศึกษา ไม่ใช่คำแนะนำในการลงทุน
